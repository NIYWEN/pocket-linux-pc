# Pocket Linux PC (代号：装逼机一号)

基于核桃派Zero W的便携式Linux命令行掌机

## 硬件清单
- 核桃派Zero W (1GB)
- 2.8寸 SPI 屏幕
- 自建转接PCB板
- 3D打印外壳
