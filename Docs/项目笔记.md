# **大一暑假手搓小电脑总结**

##### 通过从买元器件，到自己设计元器件排列，再到画PCB板，随后练习焊接，烧录系统，配置屏幕，下载屏幕驱动，绘制3D外壳，一共从2026年7月12日零零散散干到2026年8月5日，历时24天。在最后在lcd显示屏显示出核桃派命令行的那一刻，我的装逼机一号已经完成。当然，我的装逼机一号还有很多不足，中间对于时间的调度也不是特别的完美，但是这才给了后续装逼机二号问世的机会。

## 零 做小电脑的启源和初衷

最开始通过 B 站发现了一些大佬自制掌机的过程，进而上网搜索这种掌机上能运行什么程序，发现是一种基于 Linux 命令行的掌机。由于还没学习 Linux，也不知道 Linux 具体是什么，经过查阅，发现 Linux 是一种更加简洁的操作系统内核，对计算机系统有着更强的掌控，并且对内存的要求也没有桌面版电脑那么高。

于是决定自己手搓一台可以运行 Linux 命令行的掌机，不仅可以随身携带，还可以尝试用小电脑控制外设，如果未来有研究网络安全的需求，也能作为一台独立电脑充当攻击的靶机。

------

## 一 选择配件和型号

由于目前树莓派价格比较高，选择了国产性价比高的核桃派 Zero W 作为主板。预算只有 200 元，所以选了 1G 内存。也没有选择核桃派的扩展板和屏幕，打算自己画转接板连接屏幕，这样价格更低廉，但对技术要求比较高。

通过研究计算机的构成，决定先做一个最低配版的小电脑，只具有显示屏、主板，以及一个能将主板剩余 GPIO 接口转接出来的转接口，方便后期直接用杜邦线插上控制外设。

## 二 思考布局和绘制 PCB 板

最开始没打算做转接板，但上网发现屏幕要跟主板连接，要么做成转接板，要么就得买官方拓展板。虽然项目开始前连 PCB 是什么都不知道，丝毫不懂 PCB 绘制原理，但转接板只需要将屏幕走线和主板走线连接到一起，再把剩余没用的 GPIO 口连到拓展口就行。整个原理和绘制觉得并没有什么困难，于是下载了嘉立创 PCB，通过 B 站 30 分钟学习了解了嘉立创要画原理图、PCB 绘制以及基本操作，就开始在实践中学习。

查询了显示屏 FPC 接口和主板接口，通过原理图进行大致连线。随后思考了整个 PCB 板的布局，最终决定在 PCB 板上开一个口，让 FPC 走线通过挖孔将屏幕翻折到另外一端，缺陷是显示屏会显得长一块。

在纸上绘制好大体布局后，开始查找显示屏、核桃派以及其他部件的尺寸图，用直尺比对方位，将所有数据体现在 PCB 板绘制上。绘制过程中仔细思考了每个开孔的方位和用途，避免了很多致命性错误。

但最后一步走线属实没那么容易，发现单层板上的两根走线无法交叉，需要打孔连通上下层。多方查阅资料后，在 AI 走线的帮助下完成了整个线路绘制。但在最终交付界面，发现无法使用嘉立创免费 PCB 打版券，查阅规则后发现是 PCB 板长度多出 4 厘米，不符合免费打版规则。

本着减少花费的原则，重新修改了 PCB 板布局，修改长度并重新走线。有了第一次走线练习，修改后的完成速度大大提升。最终决定将 FPC 设置在整个板的最末端，用排线将显示屏连接出来以后弯折到 PCB 板背面，这样就能完成正面显示屏、背面是主板和接口的布局，大大节省空间，尺寸也缩短到免费打板规则之内。

------

## 三 烧录系统

板子还没到的时候，决定先给核桃派烧录系统。但由于板子没回来，且当时没考虑输入输出问题，所以没有 HDMI 转 Micro HDMI 线，也没有将核桃派 Type-C 转 USB 的线（可通过键盘鼠标控制，OTG 转接口），造成既看不见输出，也无法输入，完全不知道是否烧录完成。

本来想通过写启动文件让板子连接 WiFi，以便用电脑 SSH 远程连接，但在烧录过程中，核桃派没放稳摔到地上，TF 卡直接摔断了。这一阶段陷入僵局，暂且搁置了烧录任务，等待网购的新 TF 卡送来。

------

## 四 焊接元件

在等待板子送来的时间里，开始研究焊接注意事项。高中有过焊接经验，所以非常自信，但仔细了解所画元件的规格和焊接方法后，不禁冒了冷汗。

当初画 PCB 时为了省几毛钱，把 0603 电阻换成了 0402 电阻，将米粒大小的电阻变成了发丝粗细。FPC 座子更有"十人九不会"的恐怖名号。于是买了练习板练习焊接，准备了更顺手的工具和吸锡带。

在不懈练习下成功焊出了 FPC 座子和 0402 电阻，焊点也比高中时期更加光滑，减少了虚焊。将 PCB 板焊接成功，但由于家里没有万用表，对焊接质量并不肯定。不过后面的使用过程中，硬件连接都非常稳定，没有出现问题。

------

## 五 连接屏幕主板，下载屏幕驱动

最大的问题出现在连接屏幕时，发现 FPC 座子和想象的方向正好相反，意味着屏幕无法翻到背面，而是正好在核桃派和转接板的正上方。这让整体电脑构造发生了巨大改变，不得不改变结构。

经过冥思苦想，决定通过翻盖方式来解决屏幕与主板、拓展口重合的问题，这也导致后续外壳设计不如原来的结构容易。重新接好屏幕后虽然亮了，但始终是白屏。

索性在家里找到了 Micro HDMI 转 HDMI 线，妈妈又帮我在附近找到了转接口售卖处。于是可以通过键盘输入、电视输出来操作。在网上查找相关教程后，成功下载屏幕驱动，画面从白屏显示出 Linux 系统。

至此，计算机框架大体构建完成。

------

## 六 绘制 3D 模型并打印外壳

在使用小电脑过程中，发现 FPC 连接有些脆弱，需要设计外壳固定屏幕和主板，才能保证走线和屏幕显示稳定。进一步细化了之前的结构图，将外壳分为屏幕翻盖部分和主机整体部分。

通过艰难下载 SolidWorks 及 30 分钟快速上手，开始了边画边学的过程。脑中建构并用尺子不断测量，在网络上开源铰链的加持下，渐渐画出了大体构造。但有一次模拟 3D 时，发现这种结构无法让 FPC 走线顺利通过，于是进行了一系列修改，最终上传到嘉立创 3D 打印平台。

但上传时发现网络开源模型中间的缝隙小于嘉立创平台给的数据，可能会导致模型粘连，而且这个模型设计的转轴非常细，不够结实。于是打算模仿铰链结构自己画一个结实版，但测量后发现要让铰链结实就得有一厘米厚，外壳会有巨大凸起，并不美观，所以决定直接上网买金属铰链，用胶粘起来。

------

## 七 外壳组装

等待 3D 外壳回来时，非常担心用普通尺子测量会产生偏差，但由于多次进行现实模拟、精细测量，并对整个结构有扎实把握，3D 模型画得非常贴合，没有出现问题。

在结构设计方面，完成了外壳的精确建模，各零件安装位与实物尺寸匹配良好。由于这是首次进行 3D 打印结构设计，尚未掌握卡扣和滑槽等可拆装结构的建模方法，最终采用透明胶带对上下盖进行了固定。这一方案虽然有点丑，也没有 3D 打印的美感，但保证了整体强度和稳定性。

------
